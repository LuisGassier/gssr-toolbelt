---
name: frontend-polish
description: Mejora visual y UX de interfaces web existentes sin romper funcionalidad.
---

# Objetivo

Elevar calidad visual, jerarquia y legibilidad en interfaces frontend.

# Cuando usar

- Redisenar vistas existentes.
- Corregir interfaces planas o inconsistentes.
- Mejorar espaciado, tipografia, color y estados UI.

# Reglas

- Respetar el sistema visual existente si ya esta definido.
- Evitar cambios estructurales innecesarios.
- Mantener accesibilidad basica (contraste, focus visible, labels).
- Verificar responsive en mobile y desktop.

# Flujo

1. Auditar problemas de jerarquia, contraste y layout.
2. Definir tokens minimos (color, spacing, radius, sombras).
3. Aplicar mejoras por secciones, no cambios aleatorios.
4. Validar que no haya regresiones funcionales.

# Salida esperada

- UI mas clara y consistente.
- Mejor lectura de contenido.
- Componentes con estados visuales definidos.
