# Final Quality Gate

Before final output, verify:

- The active mode was identified.
- Evidence was inspected before asking questions.
- Existing UI was not preserved blindly.
- Functionality and accessibility were preserved.
- The intervention level matches the real problem.
- Screenshots or references were translated, not copied.
- Responsive behavior was considered.
- System-wide impact was considered.
- The output avoids cosmetic-only fixes.
- The result connects back to the client goal.
