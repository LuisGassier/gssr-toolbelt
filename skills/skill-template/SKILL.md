# Objetivo

Describe aqui el objetivo principal del skill en 1-2 lineas.

# Cuando usar

Usa este skill cuando:

- El usuario pida una tarea claramente dentro del dominio del skill.
- Exista una salida concreta y verificable.

# Cuando no usar

No usar cuando:

- La tarea no corresponde al dominio del skill.
- Haya otro skill mas especifico para ese caso.

# Flujo recomendado

1. Confirmar el contexto minimo necesario.
2. Ejecutar acciones en el orden mas seguro.
3. Validar resultados (errores, lint, tests o salida esperada).
4. Entregar resumen claro y siguientes pasos.

# Checklist de calidad

- Alcance definido.
- Restricciones explicitas.
- Pasos accionables.
- Resultado verificable.
